## A1：全量長度統計與模擬

腳本：`node docs/verify-claude-stats.mjs`；輸出 `docs/verify-claude-stats.json`。

方法：讀取所有題庫 JSON，排除 draft／retired，以選項原始文字 JavaScript `.length`（UTF-16 code units）計長。最長並列時固定選題庫中先出現者；另提供並列隨機抽選的期望得分，避免藏匿 tie-break 的影響。百分比為本題庫逐題正確率，不是正式考試成績預測。

| 指標 | Codex 實測 |
|---|---:|
| 題數 | 835 |
| 正解唯一最長 | 641／835＝76.7665% |
| 正解為最長之一 | 744／835＝89.1018% |
| 每題正解平均長度／誘答平均長度，再對題目取平均 | 2.271979 倍 |
| 全部正解平均長度／全部誘答平均長度 | 2.274827 倍 |
| 題內長度比 ≥3 | 200 題 |
| 固定並列取第一個的最長策略 | 676／835＝80.9581% |
| 並列最長隨機選的期望 | 80.9381% |
| 非程式題 | 652／755＝86.3576% |
| 程式題 | 24／80＝30.0% |

所以 Claude 的 76.8%、2.27倍、81.0%、86.4%、30.0% 均能重現。但長度比需說明是「比值的平均」或「平均的比值」；本庫兩者恰好四捨五入相同，不應視為一般恆等。

| 科目 | 答對／題數 | 最長策略得分 |
|---|---:|---:|
| L11 | 146／187 | 78.0749% |
| L12 | 122／137 | 89.0511% |
| L21 | 122／135 | 90.3704% |
| L22 | 147／195 | 75.3846% |
| L23 | 139／181 | 76.7956% |

**效度判斷**：不閱讀學科內容的機械規則就能超過80%，明顯存在與知識無關的答題線索，對把平台成績當成理解程度的解釋構成重大威脅。同意優先改善；但不能由此宣稱正式 iPAS 題目一定沒有長度線索，也不能量化本站分數相對正式考試高估多少，因本次沒有取得正式題庫統計或真實考生對照資料。

編題原則可參照 [NBME 官方編題指引資源](https://www.nbme.org/institutions/nbme-item-writing-guide/) 與 [NBME 編題指引正文（大學存檔）](https://programevaluation.med.ufl.edu/files/2010/07/NBME-Item-Writing-Guide.pdf)：正解過長、過完整以及絕對字詞均屬可能提示答案的技術缺陷。這是編題原則參考，不是 iPAS 官方品質標準。

**合理改善目標（本專案建議，不是官方效度門檻）**：

- 分批改寫長度極端或誘答不合理的題目，先讓全庫及各科最長策略低於40%，再以25%～35%作長期監測區間；並列隨機期望與固定取第一個都需看，避免只是改動排序。
- 四選一完全均勻亂選的基準為25%，但達25%～35%本身不能證明效度；也不能硬性要求所有選項等長。
- 長度比1.5倍適合作人工複查警告，不宜直接拒絕題目。保留必要限定、穩定ID與正解，不用灌字或刪掉正確前提來湊長度。
- 再以真正作答資料評估題目鑑別度、誘答選擇率與覆蓋範圍，配合專業審閱；自動統計不等於人工審核通過。

## A2：絕對詞與抽樣誘答

以 `/一定|絕對|永遠|完全|所有|只要|必定|只能/` 對**選項文字**搜尋，以題為單位：至少一個錯誤選項命中306題，至少一個正確選項命中11題。兩群可重疊，不能相加當成互斥題數，也不是306個錯誤選項。數字與 Claude 一致。

另外獨立抽查10題：從錯誤選項含絕對詞的題目按ID排序，每31題取一題，前10個；完整輸入在 `docs/verify-claude-sample.json`。這是刻意針對該問題家族的系統抽樣，**不是全庫隨機樣本**，沒有重現或冒稱 Claude 未提供種子的「12題中8題」比例。

| 題目 | 實際誘答與判讀 |
|---|---|
| L12202-0011 | 「讓模型真的取得財務分析師執照」：角色提示的情境中明顯不合理 |
| L21101-0010 | 「只保留每段對話的第一個字」：隱私前處理問題中不具實務合理性 |
| L22103-0015 | 「樣本平均等於 p 值」：與虛無假設的任務不匹配，可不理解檢定便排除 |
| L11402-0014 | 「只要模型夠聰明就會自動保密」：極端化且缺乏可用的權限控管理由 |
| L23303-0008 | 「R²不可能為負，一定是算錯」：屬常見誤解，有教學價值，不應只因絕對詞就刪除 |
| L23103-0011 | 「梯度永遠為0」：過於極端；相較之下對凸性的局部／全域、唯一性混淆更適合測觀念 |

因此 A2 的品質問題成立，但不能據此說306題的所有誘答都無效。基礎題偶爾用來診斷迷思合理；問題是同類線索大量聚集。改善應以語意與常見錯誤為主，不是刻意增加正解中的絕對詞來達成字面平衡。

## B1：並發補強題提交

獨立測試同時對 `recordTutorAttempt()` 呼叫兩次：

```json
{"originalQuestionId":"original-L11101-0001","questionId":"original-L11101-0002","selected":["A"],"timeMs":1000}
```

實際輸出：`attempts=2`、該補強題 `mistakeCount=2`。使用隔離 fake-indexeddb 資料庫，沒有碰使用者日常瀏覽器。

TutorPanel 的 submit 在 await 前只有 `result !== null` 檢查；直到 await 後才 setResult，沒有同步 ref 鎖或送出中狀態。資料層 transaction 能序列化兩次寫入，但沒有冪等條件，不能因此防重。與 Claude 的資料層重現一致。

應以單次導師互動的穩定提交識別碼做資料層冪等，加上同步鎖／busy UI；不能單用「原題＋補強題」永久去重，否則會阻止使用者之後合法再次複習。
