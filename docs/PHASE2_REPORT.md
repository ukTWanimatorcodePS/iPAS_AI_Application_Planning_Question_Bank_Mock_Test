## Phase C：AI 導師

- `src/ai/`：Provider 介面、示範模式（離線，預設）、遠端代理模式（需建置時設定 `VITE_AI_TUTOR_ENDPOINT`）。
- 流程：核心考點 → 為什麼選錯 → 換例子重教 → 正確觀念 vs. 常見誤解 → 補強題 → 依結果調整排程（答錯：原題改今天到期；答對：不會直接「已掌握」）。
- 模式：簡單解釋、詳細教學、舉例說明、比較易混淆觀念、再出一題。
- 安全：前端無任何 API 金鑰欄位；請求只包含 `questionId`（題目 ID）、`selected`（使用者選項）、`mode`（教學模式）、`exclude`（本次已出過的補強題 ID），不含個人資料；遠端回應經 schema 驗證，補強題必須是題庫內同細項題目；內容一律標示來源（示範／AI 生成）。說明見 `docs/AI_TUTOR.md`。
- 資料：IndexedDB v2 新增 `tutorLogs`；新增作答模式 `tutor`。

## Phase D：智慧學習

E2E 涵蓋：學習閉環、級別切換、未完成測驗恢復、深連結重整、AI 導師（模式切換、補強題影響錯題本）、學習計畫、考前衝刺、備份匯出→清除→匯入、匯入 v1 備份、拒絕不合法備份、深色＋高對比＋130% 字級、固定按鈕不遮住底部導覽、長程式碼不溢出、鍵盤「跳到主要內容」、360／768 寬度。

測試中發現並修正的問題：
1. 「跳到主要內容」使用 `href="#main"`，在 HashRouter 下會切換成不存在的路由 → 改為程式移動焦點。
2. 歷屆試題頁的題目清單在 768px 溢出 119px（grid 欄寬依最長文字計算）→ 改用 `grid-cols-1`。
3. E2E 溢出檢查原本以 `innerWidth` 比較，在手機模擬下會隨溢出內容放大而偵測不到 → 改以 `clientWidth` 比較。
4. 學習計畫在距考試不足三週時，訊息說會衝刺安排但實際只排講義 → 修正為講義與衝刺任務並行。

## 已知限制與尚未人工審核的內容

- **全部 589 題與 50 份講義皆為 AI 草擬、通過自動檢查，尚未經人工專家審核**（`reviewStatus: ai-checked`）。自動檢查只能確認結構與一致性，無法保證每一個觀念敘述都完全正確。
- 中級每細項目前 8 題，低於初級的 20 題；題型分布以概念與情境為主，「應用」難度題比例偏低（見 `npm run validate:content -- --report`）。
- 未收錄官方原題；2027 年考期與規則待官方公告後更新。
- CPython 交叉驗證只在 CI 執行（本機沒有 Python），尚未在實際 CI 上跑過。
- AI 導師只有示範模式可用；遠端模式需另建後端代理，尚未部署。
- 跨裝置同步、PWA 離線快取尚未實作。
- 尚未建立 GitHub repository，未實際部署上線。
- 部分講義外部參考連結（英文文件、論文）未逐一實際開啟確認。
