## 非阻擋支援限制：換行可以是合法填充字元

以下三引號 f-string 合法（冒號後為實際換行）：

```python
rf"""{x:
>10} \(ok\)"""
```

令 x=7 時，CPython 輸出九個換行、7 及字面文字 `\(ok\)`。掃描器在格式規格中遇到換行會返回失敗，完整保留原文，因此這個合法程式範例會被 LaTeX 檢查攔下。

本次將它標為已知保守限制，沒有將「合法字串一律不誤報」當成通過結論。它沒有造成外部公式漏攔，也不影響現有 835 題，**不視為本輪發布阻擋問題**。

建議將程式註解「格式規格不能跨行」改為「本掃描器保守不支援格式規格中的換行」以免誤述 Python 語法；後續若要支援，再補對應狀態與測試。本次未修改正式程式。
