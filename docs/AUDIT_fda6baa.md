其中前兩種就在現有內容，證明 0 錯誤不代表該類錯誤已清除。應加入常見標點／等號／措辭變體的測試，且分開處理正解解析與誘答文字。測試 CORRECT 陣列的「一定是凸函數，只有一個最小值」其實來自錯誤選項，不能因需容許誘答而籠統稱作「正確說明」；應以欄位上下文容許合理誘答，而不是把錯誤命題當作普遍免報範例。
