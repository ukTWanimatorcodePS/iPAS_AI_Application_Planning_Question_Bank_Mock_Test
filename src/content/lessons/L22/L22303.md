## 學習目標

- 依資料型態與溝通目的選擇合適圖表：比較、趨勢、分佈、組成、關係。
- 掌握視覺化設計原則：資料墨水比、正確座標軸、色彩與無障礙、避免誤導。
- 認識常用工具（Python matplotlib／seaborn、BI 工具）與儀表板設計要點。

## 先備概念

- L22101：敘述統計與箱形圖。

## 必考核心觀念

- 比較用長條圖；趨勢用折線圖；分佈用直方圖或箱形圖；關係用散佈圖；組成用堆疊長條圖（圓餅圖只適合少數類別）。
- 長條圖的數值軸應從 0 開始，截斷座標軸會誇大差異。
- 色彩不應是唯一的資訊來源，需考慮色盲友善並搭配標籤或圖樣。
- 儀表板應聚焦關鍵指標（KPI），提供篩選與下鑽，並說明資料更新時間與定義。
- 視覺化的目的是溝通：先確定受眾與要傳達的一句話結論。

## 名詞與定義

- **直方圖（Histogram）**：顯示數值資料在各區間的次數分佈。
- **箱形圖（Box Plot）**：以四分位數顯示分佈與異常值。
- **散佈圖（Scatter Plot）**：顯示兩數值變數的關係。
- **熱力圖（Heatmap）**：以顏色深淺表示矩陣數值，如相關係數矩陣。
- **資料墨水比（Data-Ink Ratio）**：圖表中用於呈現資料的墨水占總墨水的比例。
- **下鑽（Drill-down）**：從彙總層級點選進入更細的資料。
- **儀表板（Dashboard）**：在單一畫面整合多個關鍵指標的視覺化介面。

## 原理及運作流程

### 1. 圖表選擇

| 目的 | 推薦圖表 | 避免 |
| --- | --- | --- |
| 比較類別大小 | 長條圖 | 3D 長條圖 |
| 呈現時間趨勢 | 折線圖 | 類別順序混亂的長條圖 |
| 呈現分佈 | 直方圖、箱形圖 | 只給平均值 |
| 呈現兩變數關係 | 散佈圖（可加迴歸線） | 雙 Y 軸誤導 |
| 呈現組成比例 | 堆疊長條圖、少數類別的圓餅圖 | 十幾個切片的圓餅圖 |
| 呈現多變數相關 | 熱力圖 | 過多顏色 |

### 2. 設計原則

- 移除不必要的裝飾（格線、陰影、3D），提高資料墨水比。
- 座標軸、單位、資料來源與更新時間標示清楚。
- 長條圖從 0 開始；折線圖可依變化範圍調整，但需標明。
- 用顏色強調重點，而非讓每個類別都很鮮豔；確保色盲友善與足夠對比。

### 3. Python 範例

```python
import matplotlib.pyplot as plt

months = ["1月", "2月", "3月", "4月"]
sales = [120, 135, 128, 160]
plt.plot(months, sales, marker="o")
plt.title("月營收趨勢（萬元）")
plt.ylabel("營收")
plt.show()
```

### 4. 儀表板設計

1. 確定使用者與決策（主管看 KPI、分析師看細節）。
2. 最重要的指標放左上方，相關指標分組。
3. 提供時間、地區等篩選與下鑽。
4. 標示指標定義與資料更新時間，避免誤解。

## 不同領域的實際案例

- **零售**：主管儀表板顯示營收、毛利、來客數與同期比較，點選地區可下鑽到門市。
- **製造**：以箱形圖比較各機台的產品尺寸分佈，快速找出變異大的機台。
- **行銷**：以散佈圖呈現廣告支出與轉換數的關係。
- **新聞媒體**：截斷縱軸讓 2% 的差異看起來像兩倍，屬誤導性圖表。

## 容易混淆的觀念比較

| 比較 | A | B | 判斷重點 |
| --- | --- | --- | --- |
| 長條圖 vs. 直方圖 | 類別比較，長條間有間隔 | 數值分佈，區間相連 | 橫軸是類別還是數值區間 |
| 折線圖 vs. 散佈圖 | 時間趨勢 | 兩變數關係 | 橫軸是否為時間 |
| 圓餅圖 vs. 長條圖 | 少數類別的組成 | 多類別的比較 | 類別數量 |
| 報表 vs. 儀表板 | 固定格式、定期產出 | 互動、即時監控 | 使用情境 |

## 常見考試陷阱

- ❌ 「長條圖的縱軸可以從任意值開始」→ 會誇大差異。
- ❌ 「3D 圖表比較專業」→ 3D 透視會扭曲比例。
- ❌ 「用紅綠兩色就能區分好壞」→ 對紅綠色盲不友善，應搭配符號或文字。
- ❌ 「一張儀表板放越多圖越好」→ 應聚焦關鍵指標。

## 單元重點整理

1. 依目的選圖：比較、趨勢、分佈、關係、組成。
2. 避免截斷座標軸、3D 與過多裝飾。
3. 顏色不是唯一資訊來源，注意無障礙。
4. 儀表板聚焦 KPI、提供篩選下鑽、標示定義與更新時間。
