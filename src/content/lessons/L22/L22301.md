## 學習目標

- 將統計方法應用於大數據分析：抽樣、估計、相關與迴歸、異常偵測。
- 理解大樣本下「統計顯著但不重要」的問題，以及相關不等於因果。
- 能用 Python 計算相關係數並判讀簡單線性迴歸結果。

## 先備概念

- L22101：敘述統計。
- L22103：假設檢定。

## 必考核心觀念

- 大數據不代表不需要抽樣：抽樣可降低成本，但要避免抽樣偏差。
- 皮爾森相關係數 r 介於 −1 到 1，只衡量線性關係；r 接近 0 不代表沒有任何關係。
- 相關不等於因果：需考慮干擾變數、反向因果與巧合，因果推論需實驗或適當方法。
- 簡單線性迴歸 y = a + bx，b 表示 x 每增加 1，y 平均變化多少；R² 為解釋變異比例。
- 樣本極大時，微小差異也會統計顯著，必須同時看效果量。

## 名詞與定義

- **抽樣偏差（Sampling Bias）**：樣本無法代表母體，導致推論偏誤。
- **分層抽樣（Stratified Sampling）**：依群組比例分別抽樣。
- **皮爾森相關係數（Pearson r）**：衡量兩變數線性關係的強度與方向。
- **干擾變數（Confounder）**：同時影響兩變數，造成假性相關的第三變數。
- **辛普森悖論（Simpson's Paradox）**：分組後與合併後的趨勢方向相反。
- **殘差（Residual）**：實際值減去預測值。

## 原理及運作流程

### 1. 抽樣

- **簡單隨機抽樣**：每筆被抽中的機率相同。
- **分層抽樣**：依地區、客群等分層，確保各層都有代表。
- **系統抽樣**：每隔 k 筆抽一筆，需注意資料是否有週期性。
- 線上自願填答的問卷容易有**自我選擇偏差**。

### 2. 相關分析

$$r=\frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum (x_i-\bar{x})^2}\sqrt{\sum (y_i-\bar{y})^2}}$$

```python
import numpy as np

ads = np.array([1, 2, 3, 4, 5])      # 廣告支出
sales = np.array([2, 4, 6, 8, 10])  # 銷售額
r = np.corrcoef(ads, sales)[0, 1]
print(r)            # 0.9999999999999999：浮點數誤差，實際上是完全正相關
print(round(r, 4))  # 1.0
```

### 3. 簡單線性迴歸

以最小平方法估計 $y=a+bx$：

- 斜率 b：x 每增加一單位，y 的平均變化。
- R²：模型解釋 y 變異的比例。
- 檢查殘差：殘差應無明顯規律，否則可能遺漏非線性關係或重要變數。

### 4. 相關 vs. 因果

冰淇淋銷量與溺水事件正相關，真正原因是「天氣炎熱」（干擾變數）。要推論因果，可用隨機對照實驗（A/B 測試），或在觀察資料中控制干擾變數。

### 5. 大樣本陷阱

百萬筆資料中，兩組平均差 0.1% 也可能 p < 0.001。決策時應看效果量、信賴區間與商業價值。

## 不同領域的實際案例

- **零售**：以分層抽樣從千萬筆交易中抽出 1% 分析，確保各地區門市都有代表。
- **行銷**：發現廣告支出與營收高度相關，但旺季同時影響兩者，需控制季節因素。
- **人資**：分析加班時數與離職率的關係，再以迴歸控制部門與年資。
- **醫療**：某療法在各年齡組都較有效，合併資料卻顯示較差（辛普森悖論），原因是年齡組成不同。

## 容易混淆的觀念比較

| 比較 | A | B | 判斷重點 |
| --- | --- | --- | --- |
| 相關 vs. 因果 | 兩變數一起變動 | 一個變數導致另一個 | 需實驗或控制干擾 |
| r vs. R² | 線性相關強度與方向（−1～1） | 解釋變異比例（0～1） | 簡單迴歸中 R² = r² |
| 簡單隨機 vs. 分層抽樣 | 整體隨機 | 各層分別抽樣 | 小群體是否需保證代表 |
| 統計顯著 vs. 效果量 | 是否可能是巧合 | 差異有多大 | 大樣本時特別重要 |

## 常見考試陷阱

- ❌ 「r = 0 代表兩變數完全無關」→ 只代表沒有線性關係，可能有非線性關係。
- ❌ 「相關性高就能推論因果」→ 可能有干擾變數或反向因果。
- ❌ 「資料夠大就不會有偏差」→ 若資料來源本身有偏差，量再大也無法修正。
- ❌ 「R² 高就代表模型一定正確」→ 仍需檢查殘差與是否遺漏變數。

## 單元重點整理

1. 抽樣要避免偏差；分層抽樣確保各群體代表性。
2. 相關係數衡量線性關係；相關 ≠ 因果。
3. 迴歸斜率表示平均變化量，R² 為解釋比例，需檢查殘差。
4. 大樣本下要看效果量而非只看 p 值。
