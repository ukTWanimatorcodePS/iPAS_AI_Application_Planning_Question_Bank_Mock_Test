## 必考核心觀念

- 大數據 5V：Volume（量）、Velocity（速度）、Variety（多樣性）、Veracity（真實性）、Value（價值）。
- ETL 先轉換再載入；ELT 先載入資料湖或倉儲再轉換，雲端常用 ELT。
- 網路爬取需遵守網站條款、robots.txt、著作權與個資規範，不可過度請求造成對方負擔。
- 資料清理要可重現：以程式碼記錄每一步，並保留原始資料。
- 資料驗證規則（型別、範圍、唯一性、參照完整性）應自動化，在管線中及早攔截錯誤。

## 名詞與定義

- **5V**：描述大數據特性的五個面向。
- **ETL**：Extract（擷取）→ Transform（轉換）→ Load（載入）。
- **ELT**：先載入再轉換，利用資料倉儲的運算能力。
- **CDC（Change Data Capture）**：只擷取資料庫的變動紀錄，降低擷取負擔。
- **資料驗證（Data Validation）**：以規則檢查資料是否符合預期。
- **去重（Deduplication）**：移除重複紀錄。

## 原理及運作流程

### 1. 蒐集方式

| 來源 | 方式 | 注意事項 |
| --- | --- | --- |
| 交易系統資料庫 | 批次匯出、CDC | 避免影響線上系統效能 |
| 應用程式日誌 | 日誌收集器、串流 | 格式統一、個資遮罩 |
| 感測器／IoT | 串流（訊息佇列） | 時間同步、遺失訊號 |
| 外部 API | 排程呼叫 | 速率限制、授權 |
| 網路爬取 | 爬蟲程式 | 網站條款、robots.txt、著作權、個資 |

### 2. ETL 與 ELT

- **ETL**：在載入前於中介伺服器轉換，適合結構固定、資料量中等的情境。
- **ELT**：先把原始資料載入資料湖或雲端倉儲，再以 SQL 轉換；保留原始資料、彈性高。

### 3. 清理步驟（pandas）

```python
import pandas as pd

df = pd.DataFrame({
    "id": [1, 2, 2, 3, 4],
    "age": [25, None, None, 230, 41],
    "city": ["Taipei", "taipei ", "taipei ", "Tainan", None],
})
df = df.drop_duplicates()                          # 去除完全相同的列 → 剩 4 列
df["city"] = df["city"].str.strip().str.title()    # 統一大小寫與空白
df.loc[(df["age"] < 0) | (df["age"] > 120), "age"] = None  # 不合理值視為缺失
df["age"] = df["age"].fillna(df["age"].median())   # 以中位數填補
print(len(df), df["age"].tolist())                 # 4 [25.0, 33.0, 33.0, 41.0]
```

### 4. 資料驗證規則

- 型別：日期欄位能否解析、數值欄位是否為數字。
- 範圍：年齡 0～120、金額 ≥ 0。
- 唯一性：主鍵不重複。
- 參照完整性：訂單的會員編號必須存在於會員表。
- 驗證失敗的資料隔離到「待處理區」，並通知負責人。

## 不同領域的實際案例

- **電商**：以 CDC 擷取訂單資料庫變動，每 5 分鐘同步到資料倉儲，避免整表匯出影響效能。
- **物聯網**：感測器資料經訊息佇列串流進入平台，遺失的時間點以前後值插補並標記。
- **市場研究**：爬取公開商品價格前，先確認網站使用條款並控制請求頻率。
- **醫療**：病歷系統匯出資料時，先遮罩身分證字號再進入分析環境。

## 容易混淆的觀念比較

| 比較 | A | B | 判斷重點 |
| --- | --- | --- | --- |
| ETL vs. ELT | 先轉換再載入 | 先載入再轉換 | 轉換發生的位置 |
| 全量擷取 vs. CDC | 每次匯出全部 | 只擷取變動 | 資料量與系統負擔 |
| Volume vs. Velocity | 資料量大 | 產生速度快 | 5V 的不同面向 |
| 刪除缺失 vs. 填補缺失 | 簡單但可能損失資訊 | 保留資料但可能引入偏差 | 缺失比例與機制 |

## 常見考試陷阱

- ❌ 「公開網頁的資料都可以任意爬取使用」→ 需遵守條款、著作權與個資規範。
- ❌ 「清理時直接覆寫原始資料」→ 應保留原始資料並以程式碼記錄步驟。
- ❌ 「Veracity 指資料量很大」→ Veracity 是資料的可信度與品質。
- ❌ 「ELT 不需要任何轉換」→ 只是轉換在載入之後進行。

## 單元重點整理

3. 清理：去重、標準化、異常值、缺失值，並保持可重現。
