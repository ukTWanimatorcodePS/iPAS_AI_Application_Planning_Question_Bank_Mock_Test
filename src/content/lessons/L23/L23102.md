## 學習目標

- 以向量與矩陣表示資料、特徵與模型參數，理解矩陣乘法與維度規則。
- 理解內積、範數與餘弦相似度在相似度計算與嵌入檢索中的應用。
- 認識特徵值分解、奇異值分解（SVD）與主成分分析（PCA）的降維概念，並能用 NumPy 計算。

## 先備概念

- L11202：特徵縮放。

## 必考核心觀念

- 資料集常表示為 n×d 矩陣（n 筆資料、d 個特徵）；線性模型預測為 ŷ = Xw + b。
- 矩陣乘法 (m×n)(n×p) = (m×p)，前者的欄數必須等於後者的列數。
- 餘弦相似度 = 內積 ÷（兩向量長度相乘），只看方向不看長度，常用於文字嵌入比對。
- PCA 找出資料變異最大的方向（主成分），用較少維度保留最多資訊；使用前通常需標準化。
- L1 範數（絕對值和）與 L2 範數（平方和開根號）也用於正則化。

## 名詞與定義

- **向量（Vector）**：有序的一組數字，可表示一筆資料或參數。
- **矩陣（Matrix）**：二維數字陣列，可表示資料集或線性轉換。
- **內積（Dot Product）**：對應元素相乘後加總。
- **範數（Norm）**：向量的長度，常見 L1、L2。
- **餘弦相似度（Cosine Similarity）**：兩向量夾角的餘弦值，介於 −1 到 1。
- **特徵值／特徵向量**：矩陣作用後方向不變的向量及其縮放倍數。
- **主成分分析（PCA）**：以正交主成分降維、保留最大變異的方法。

## 原理及運作流程

### 1. 資料與模型的矩陣表示

- 資料矩陣 $X\in\mathbb{R}^{n\times d}$，權重向量 $w\in\mathbb{R}^{d}$。
- 線性模型：$\hat{y}=Xw+b$。
- 神經網路每一層：$h=\sigma(Wx+b)$。

### 2. 矩陣運算與 NumPy

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print((A @ B).tolist())  # [[19, 22], [43, 50]]
print((A * B).tolist())  # [[5, 12], [21, 32]]：逐元素相乘，不是矩陣乘法
print(A.T.tolist())      # [[1, 3], [2, 4]]：轉置
```

### 3. 相似度與範數

$$\cos\theta=\frac{a\cdot b}{\lVert a\rVert\,\lVert b\rVert}$$

```python
import numpy as np

a, b = np.array([1, 0]), np.array([1, 1])
cos = a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
print(round(float(cos), 3))  # 0.707
```

- L2 範數：$\lVert x\rVert_2=\sqrt{\sum x_i^2}$；L1 範數：$\sum |x_i|$。

### 4. 降維：PCA 與 SVD

1. 標準化各特徵。
2. 計算共變異數矩陣的特徵值與特徵向量（或對資料做 SVD）。
3. 依特徵值大小排序，取前 k 個主成分。
4. 解釋變異比例 = 前 k 個特徵值總和 ÷ 全部特徵值總和。

PCA 可用於視覺化、去除共線性、壓縮資料，但主成分是原特徵的線性組合，可解釋性較低。

官方評鑑範圍（115.06）本細項列出「特徵提取、資料降維與壓縮」：

- **特徵提取**：PCA 把原本 d 個特徵轉換成 k 個新特徵（主成分），屬於產生新特徵的特徵提取，而不是從原特徵中挑選的特徵選擇。
- **壓縮**：只保留前 k 個奇異值與對應向量（截斷 SVD）即可近似重建原矩陣，用較少的數字儲存大部分資訊，例如影像壓縮與推薦系統的矩陣分解。

## 不同領域的實際案例

- **語意搜尋**：問題與文件轉為嵌入向量後，以餘弦相似度找出最相近的段落（RAG）。
- **推薦系統**：以矩陣分解（SVD）把使用者—商品評分矩陣分解為潛在因子。
- **製造**：數百個感測器特徵以 PCA 降到 10 維，用於異常偵測與視覺化。
- **影像**：一張 28×28 灰階圖可攤平為 784 維向量輸入模型。

## 容易混淆的觀念比較

| 比較 | A | B | 判斷重點 |
| --- | --- | --- | --- |
| 矩陣乘法 vs. 逐元素相乘 | `A @ B` | `A * B` | NumPy 運算子不同 |
| 內積 vs. 餘弦相似度 | 受向量長度影響 | 只看方向 | 文字相似度多用餘弦 |
| L1 vs. L2 範數 | 絕對值和 | 平方和開根號 | 正則化效果不同 |
| PCA vs. 特徵選擇 | 產生新的組合特徵 | 保留原特徵子集 | 可解釋性 |

## 常見考試陷阱

- ❌ 「(2×3) 矩陣可以乘 (2×3) 矩陣」→ 內側維度必須相同。
- ❌ 「NumPy 的 * 是矩陣乘法」→ * 是逐元素相乘，矩陣乘法用 @。
- ❌ 「PCA 不需要標準化」→ 不同量級的特徵會主導主成分。
- ❌ 「餘弦相似度為 0 代表兩向量相同」→ 代表正交（無相關方向）。

## 單元重點整理

1. 資料矩陣 n×d，線性模型 ŷ = Xw + b。
2. 矩陣乘法維度規則；NumPy 用 @。
3. 餘弦相似度只看方向，用於嵌入檢索。
4. PCA 以特徵值／SVD 降維，使用前先標準化。

2. 兩向量方向完全相同時，餘弦相似度為多少？
