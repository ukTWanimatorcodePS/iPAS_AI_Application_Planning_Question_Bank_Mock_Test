## 學習目標

- 辨識機器學習生命週期中的隱私與安全風險：訓練資料外洩、成員推論、模型反演、模型竊取、資料投毒、對抗樣本。
- 應用防護措施：資料最小化、存取控制、差分隱私、聯邦學習、輸入驗證、監控與稽核。
- 理解機器學習系統的合規要求：個資法、GDPR、產業規範、模型文件與紀錄。

## 先備概念

- L22404：大數據隱私、安全與合規。
- L21203：AI 風險管理。

## 必考核心觀念

- 模型本身也可能洩漏資料：成員推論判斷某筆資料是否在訓練集中；模型反演嘗試還原訓練資料特徵。
- 模型竊取：攻擊者大量查詢 API，以輸入輸出訓練出功能相似的替代模型。
- 資料投毒在訓練階段植入惡意資料或後門；對抗樣本在推論階段欺騙模型。
- 防護需涵蓋資料、模型、服務三層：去識別化與差分隱私、存取控制與加密、速率限制與輸入驗證、監控。
- 合規需要文件化：資料來源與授權、處理目的、模型卡、存取與變更紀錄，以及屬高度風險處理時的 DPIA。

## 名詞與定義

- **成員推論攻擊（Membership Inference）**：推測某筆資料是否被用於訓練。
- **模型反演（Model Inversion）**：從模型輸出推回訓練資料的特徵。
- **模型竊取（Model Extraction）**：透過查詢複製模型功能。
- **後門攻擊（Backdoor Attack）**：在訓練中植入觸發條件，使特定輸入產生攻擊者想要的輸出。
- **差分隱私訓練（DP-SGD）**：在梯度中加入雜訊並裁剪，提供隱私保證的訓練方式。
- **速率限制（Rate Limiting）**：限制單位時間內的 API 呼叫次數。

## 原理及運作流程

### 1. 威脅與防護對照

| 階段 | 威脅 | 防護措施 |
| --- | --- | --- |
| 資料蒐集 | 未經授權資料、個資過度蒐集 | 合法基礎、最小化、授權審查 |
| 訓練 | 資料投毒、後門 | 資料來源驗證、異常樣本偵測、存取控制 |
| 模型 | 成員推論、模型反演 | 差分隱私訓練、正則化（降低過擬合）、限制輸出細節 |
| 服務（API） | 模型竊取、對抗樣本、濫用 | 身分驗證、速率限制、輸入驗證、只回傳必要資訊、監控異常查詢 |

過擬合的模型更容易被成員推論攻擊，因為它對訓練資料「記得特別清楚」。

### 2. 隱私保護訓練

- **去識別化**：移除直接識別欄位、泛化準識別欄位。
- **差分隱私（DP-SGD）**：裁剪每筆資料的梯度並加入雜訊，限制單筆資料對模型的影響。
- **聯邦學習**：資料不出本地，只上傳模型更新；可搭配安全聚合。

### 3. 安全開發與營運

1. 資料、程式碼、模型的版本與存取紀錄。
2. 模型檔案視為機密資產，加密儲存並控管下載。
3. API 只回傳必要資訊（例如只回傳類別，不回傳完整機率向量），降低竊取與推論風險。
4. 監控異常查詢模式與輸入分布。

### 4. 合規文件

- 資料清冊（來源、授權、保存期限）。
- 模型卡（用途、限制、效能、公平性評估）。
- DPIA 與風險評估紀錄。
- 當事人權利處理流程（例如刪除請求對訓練資料與模型的影響）。

## 不同領域的實際案例

- **醫療 AI 公司**：以 DP-SGD 訓練疾病預測模型，降低病人資料被推論的風險。
- **API 服務商**：偵測到單一帳號短時間大量查詢，判斷可能是模型竊取，啟動速率限制。
- **影像辨識**：資料集被植入帶特定貼紙的錯誤標籤（後門），透過資料稽核發現並移除。
- **金融**：模型只對外回傳「核准／婉拒」與主要原因，不回傳完整分數。

## 容易混淆的觀念比較

| 比較 | A | B | 判斷重點 |
| --- | --- | --- | --- |
| 成員推論 vs. 模型反演 | 判斷某筆資料是否在訓練集 | 推回訓練資料特徵 | 攻擊目標 |
| 資料投毒 vs. 對抗樣本 | 訓練階段 | 推論階段 | 攻擊時機 |
| 模型竊取 vs. 資料外洩 | 複製模型功能 | 取得原始資料 | 被竊取的資產 |
| 差分隱私 vs. 聯邦學習 | 加雜訊限制個人影響 | 資料不出本地 | 可搭配使用 |

## 常見考試陷阱

- ❌ 「只要不公開訓練資料，模型就不會洩漏隱私」→ 模型可能遭成員推論或反演。
- ❌ 「API 回傳越多資訊對使用者越好」→ 也可能幫助攻擊者竊取或推論。
- ❌ 「過擬合只影響準確率」→ 也提高隱私攻擊成功率。
- ❌ 「資料投毒只會降低準確率」→ 後門可讓特定輸入產生指定輸出。

## 單元重點整理

1. 模型層面的隱私攻擊：成員推論、模型反演；安全攻擊：竊取、投毒、後門、對抗樣本。
2. 防護涵蓋資料、模型、服務三層。
3. DP-SGD、聯邦學習、速率限制、輸入驗證、最小化輸出。
4. 合規需資料清冊、模型卡、DPIA 與紀錄。

## 單元回顧

1. 攻擊者大量呼叫 API 想複製模型，屬於哪種攻擊？可用什麼防護？
2. 為什麼過擬合會增加成員推論的風險？
3. DP-SGD 的兩個關鍵步驟是什麼？（提示：1. 模型竊取，速率限制、身分驗證、限制輸出；2. 模型對訓練資料記憶過深；3. 梯度裁剪與加入雜訊。）
