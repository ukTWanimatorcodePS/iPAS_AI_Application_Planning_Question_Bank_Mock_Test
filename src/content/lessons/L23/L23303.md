## 學習目標

- 正確切分訓練、驗證、測試資料，並使用 K 折交叉驗證與分層抽樣。
- 計算並解讀分類指標（混淆矩陣、精確率、召回率、F1、ROC-AUC）與迴歸指標（MAE、MSE、RMSE、R²）。
- 辨識資料洩漏（Data Leakage）並以學習曲線診斷過擬合與欠擬合。

## 先備概念

- **L11301**：訓練／驗證／測試集、過擬合。
- **L11302**：混淆矩陣與基本指標。

## 必考核心觀念

- 驗證策略：保留法、K 折交叉驗證、分層抽樣、時間序列依時間切分。
- 分類指標：精確率、召回率、F1、ROC-AUC；迴歸指標：MAE、MSE、RMSE、R²。
- 前處理的統計量只能用訓練集計算，否則會資料洩漏（Data Leakage）。
- 學習曲線：訓練與驗證都差 → 欠擬合；差距大 → 過擬合。
- AUC 0.5 約等於隨機猜測；R² 可能為負。

## 名詞與定義

- **K 折交叉驗證（K-fold Cross Validation）**。
- **分層抽樣（Stratified Sampling）**。
- **ROC-AUC**：以曲線下面積衡量分類器區分能力。
- **資料洩漏（Data Leakage）**：評估時不當使用了不應取得的資訊。
- **偏差－變異權衡（Bias-Variance Trade-off）**。

## 原理及運作流程

### 1. 驗證策略

- **保留法（Hold-out）**：一次切分訓練／驗證／測試。
- **K 折交叉驗證（K-fold CV）**：資料分 K 份，輪流以其中 1 份驗證、其餘訓練，取 K 次平均；資料少時更穩定。
- **分層抽樣（Stratified）**：切分時維持各類別比例，適用不平衡分類。
- **時間序列切分**：只能用過去預測未來，不可隨機打亂。

### 2. 分類指標

$$\text{Precision}=\frac{TP}{TP+FP}\qquad \text{Recall}=\frac{TP}{TP+FN}\qquad F_1=\frac{2PR}{P+R}$$

- **ROC 曲線**：不同門檻下的真陽性率（召回率）對偽陽性率；**AUC** 越接近 1 越好，0.5 約等於隨機猜測。
- 調整**分類門檻**會在精確率與召回率之間取捨。

```python
tp, fp, fn, tn = 40, 10, 20, 30
precision = tp / (tp + fp)   # 0.8
recall = tp / (tp + fn)      # 0.666...
f1 = 2 * precision * recall / (precision + recall)
print(round(f1, 3))          # 0.727
```

### 3. 迴歸指標

| 指標 | 公式概念 | 特性 |
| --- | --- | --- |
| MAE | 平均絕對誤差 | 直觀、對極端誤差較不敏感 |
| MSE | 平均平方誤差 | 放大大誤差，單位為平方 |
| RMSE | $\sqrt{MSE}$ | 與原單位相同，懲罰大誤差 |
| R² | 1 − 殘差平方和／總平方和 | 解釋變異比例，可為負（比猜平均還差） |

### 4. 資料洩漏

訓練時使用了「預測當下不可能取得」或「來自測試集」的資訊，導致評估過度樂觀。常見情況：

- 在切分前就用**全部資料**做標準化或填補（應只用訓練集統計量）。
- 特徵中包含與標籤直接相關的未來資訊（例如用「是否已退款」預測「是否會退貨」）。
- 時間序列隨機切分，讓模型看到未來。

### 5. 學習曲線診斷

| 現象 | 判斷 | 對策 |
| --- | --- | --- |
| 訓練與驗證誤差都高且接近 | 欠擬合（高偏差） | 增加模型複雜度、增加特徵 |
| 訓練誤差低、驗證誤差高、差距大 | 過擬合（高變異） | 更多資料、正則化、簡化模型、Dropout、提早停止 |

## 不同領域的實際案例

- **零售需求預測**：以 2024 年資料訓練、2025 年資料測試，而非隨機切分。
- **醫療**：先在訓練集計算平均與標準差做標準化，再套用到測試集，避免洩漏。
- **信用風險**：利用 ROC-AUC 比較模型，再依業務可接受的違約損失選定門檻。

## 容易混淆的觀念比較

| 比較 | A | B | 判斷重點 |
| --- | --- | --- | --- |
| 驗證集 vs. 測試集 | 選模型、調參 | 最終評估一次 | 測試集不可反覆用來調參 |
| MAE vs. RMSE | 線性看待誤差 | 放大大誤差 | 大誤差代價高用 RMSE |
| 隨機切分 vs. 時間切分 | 一般資料 | 時間序列 | 避免看到未來 |
| 高偏差 vs. 高變異 | 欠擬合 | 過擬合 | 看訓練與驗證誤差差距 |

## 常見考試陷阱

- ❌「在整份資料上先標準化再切分沒關係」→ 會造成資料洩漏。
- ❌「AUC = 0.5 代表模型很好」→ 約等於隨機猜測。
- ❌「R² 一定介於 0 和 1」→ 模型比預測平均值還差時可為負。
- ❌「時間序列也可以隨機打亂切分」→ 會用未來預測過去。

## 單元重點整理

1. Hold-out、K-fold、分層、時間序列切分各有適用情境。
2. 分類：P、R、F1、ROC-AUC，門檻影響取捨；迴歸：MAE、MSE、RMSE、R²。
3. 前處理統計量只用訓練集計算，避免資料洩漏。
4. 學習曲線：都高＝欠擬合；差距大＝過擬合。
