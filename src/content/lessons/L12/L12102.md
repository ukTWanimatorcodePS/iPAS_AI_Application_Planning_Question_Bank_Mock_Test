## 學習目標

- 列舉 No Code / Low Code 的主要優勢：開發快、成本低、業務自主、易於迭代。
- 說明主要限制：客製化與擴充性、效能、供應商綁定、資安與治理、整合複雜度。
- 能判斷哪些情境適合採用 No Code / Low Code，哪些應採傳統開發。

## 先備概念

- **L12101**：No Code 與 Low Code 的定義與平台類型。

## 必考核心觀念

- 優勢：開發快、門檻低、貼近業務、易於迭代。
- 限制：客製化與擴充性、效能、供應商綁定（Vendor Lock-in）、資安治理、整合、授權成本。
- 適合內部流程與原型驗證（PoC）；核心系統與高併發服務需謹慎。
- 影子 IT（Shadow IT）可能造成資料外洩與無人維護。

## 名詞與定義

- **供應商綁定（Vendor Lock-in）**：過度依賴特定供應商，難以轉換。
- **影子 IT（Shadow IT）**：未經 IT 部門核准或管理的系統與應用。
- **概念驗證（PoC, Proof of Concept）**：小規模驗證想法是否可行。
- **可擴展性（Scalability）**：系統因應使用量增加的能力。

## 原理及運作流程

### 1. 優勢

| 優勢 | 說明 |
| --- | --- |
| 開發速度快 | 拖拉元件與範本，數天甚至數小時完成原型 |
| 降低技術門檻與成本 | 業務人員可自行開發，減少外包與排隊等待 IT |
| 貼近業務需求 | 最懂流程的人直接動手，減少需求轉譯落差 |
| 易於修改迭代 | 流程改變時可快速調整 |
| 促進數位轉型 | 讓更多部門參與自動化與 AI 應用 |

### 2. 限制與風險

| 限制 | 說明 |
| --- | --- |
| 客製化受限 | 功能受平台提供的元件限制，特殊邏輯難實作 |
| 擴充性與效能 | 大量使用者或大量資料時可能效能不足 |
| 供應商綁定（Vendor Lock-in） | 應用與資料依賴特定平台，轉移成本高 |
| 資安與治理 | 員工自建應用可能未經審查，造成資料外洩或「影子 IT」 |
| 整合複雜 | 與企業核心系統深度整合時仍需專業開發 |
| 授權成本 | 使用人數或執行次數增加後，訂閱費可能大幅上升 |

### 3. 適用情境判斷

**適合**：內部流程自動化、原型驗證（PoC）、部門級小型應用、需求變動頻繁、使用者數量有限。

**不適合或需謹慎**：核心交易系統、高併發對外服務、需高度客製演算法、嚴格法規要求且平台無法提供稽核能力的系統。

常見策略是**混合使用**：先用 No Code 快速驗證想法，證明價值後再由 IT 以 Low Code 或傳統開發重建為正式系統。

### 4. 治理建議

- 建立平台白名單與資料分級規範。
- 由 IT 設定權限、連接器與資料存取範圍。
- 盤點公民開發者建立的應用，指定負責人與維護機制。
- 評估資料可匯出性，降低供應商綁定風險。

### 5. 其他需要評估的事項

- **資料存放地（資料落地）**：部分產業法規或合約要求特定資料存放在國內；平台若只能存放在國外機房，受規範的資料就不應放上去。
- **MVP（最小可行產品）**：新創常先用 No Code 做出 MVP 驗證市場，用戶成長後再以專業開發重建。

## 不同領域的實際案例

- **行銷部**：用 No Code 建立活動報名頁與自動確認信，兩天上線。
- **銀行**：核心帳務系統仍採傳統開發，但分行內部的申請流程用 Low Code 平台建置。
- **新創**：先用 No Code 做出 MVP 驗證市場，用戶成長後再重寫。

## 容易混淆的觀念比較

| 比較 | A | B | 判斷重點 |
| --- | --- | --- | --- |
| 適合 No Code | 內部流程、原型 | — | 規模小、變動快 |
| 適合傳統開發 | — | 核心系統、高併發、高度客製 | 效能與控制需求高 |
| 開發成本 vs. 長期成本 | 初期低 | 授權費與轉移成本可能高 | 要看總持有成本 |
| 業務自主 vs. 治理 | 速度快 | 需 IT 監督 | 兩者需取得平衡 |

## 常見考試陷阱

- ❌「No Code 適合所有系統」→ 核心與高併發系統仍需專業開發。
- ❌「No Code 一定比較便宜」→ 授權費隨規模增加，需評估總持有成本。
- ❌「員工自建應用不需要資安審查」→ 可能造成資料外洩與影子 IT。

## 單元重點整理

1. 優勢：快、低門檻、貼近業務、易迭代。
2. 限制：客製化、擴充效能、供應商綁定、資安治理、整合、授權成本。
3. 適合內部流程與 PoC；核心系統謹慎。
4. 需 IT 治理：白名單、權限、盤點、資料可攜。
